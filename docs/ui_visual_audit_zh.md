# 《SCP档案：命运织机》UI/视觉系统深度审查与改进建议（中文）

> 目标：在保持“终端沉浸式”核心体验基础上，进一步提升高级感、SCP基金会世界观一致性与交互清晰度。

## 0. 项目视觉基因与现状理解

### 当前已形成的优势（值得保留）
- **终端基底非常明确**：全局字体以 `JetBrains Mono + Special Elite` 组成“技术终端 +档案报告”双层气质；配色以黑/灰底 + 绿色终端高亮 + 红色告警构成统一语义。  
- **SCP氛围元素齐全**：启动引导、扫描线、噪声、故障（glitch）、稳定性告警、报告导出、档案措辞都与“基金会控制台”语境贴合。  
- **状态驱动视觉逻辑已存在**：稳定度影响主题色、特效强度和警报反馈，形成了“系统健康度→视觉反馈”的闭环。  
- **信息架构已较完整**：主终端（叙事）、顶部状态、左右侧边栏（传承/地图）、结局复盘（World Tree + Review）构成可持续扩展的UI骨架。  

### 目前的主要短板（高优先级）
1. **视觉语义层级不够制度化**：终端绿、告警红、功能按钮色在某些区域混用，难形成“语义即颜色”的强规则。  
2. **“高级感”不足的来源**：部分按钮/卡片仍有“通用网页UI”质感（圆角、emoji、常规阴影），未完全进入“基金会工业控制台”设计语言。  
3. **模块风格一致性不足**：启动页、主游戏、设置/存档、NG+弹层之间的边框、排版、图标语言、微动效风格尚未完全统一。  
4. **叙事节奏与视觉节奏未深绑定**：当前特效偏“全局触发”，可进一步绑定到剧情事件类型（收容、突破、认知污染、现实扭曲）以增强“可读的视觉叙事”。

## 1) 启动 BOOTSTRAP 与开始界面

### 现状判断
- Boot 序列的打字、扫描线、跳过机制已经建立出“系统接管”仪式感。  
- 开始界面包含：SCP输入、角色矩阵、随机入口、设置入口、加载状态轮播，功能完整。  

### 改进建议
1. **引入“安全等级门禁”视觉层**（建议高优先）  
   - 在 Boot 末尾增加 `CLEARANCE CHECK` 子流程：根据玩家角色映射 L1-L5 许可级别，并在开始界面标题区域显示“当前许可”。  
   - 让“角色选择”不仅是文案列表，而是“岗位 + 许可 + 风险标签”的三列终端表格式呈现。
2. **启动页品牌统一**  
   - 将 `GameLogo`、主标题、副标题、输入区改为统一栅格（建议 12 栏，左重右轻）。  
   - 目前粒子文字效果很强，但可增加“静态 fallback 字重层”防止某些设备看起来发虚。
3. **随机 SCP 入口语义强化**  
   - 现在更像一个图形按钮；可增加小标签：`RANDOMIZED FILE INJECTION`，并显示“最后一次随机编号”历史，增强“终端操作痕迹”。
4. **加载阶段差异化**  
   - 目前是统一转圈 + 文案轮播；可拆成 4 个明确阶段（检索档案/构建场景/初始化主持/建立会话），每阶段有独立图标与可视化进度段。

## 2) 游戏核心界面（终端主区）

### 现状判断
- 核心叙事区结构清晰：消息流、输入区、系统反馈、状态联动。  
- 终端沉浸感较好，但“信息权重”与“可扫描性”还有提升空间。

### 改进建议
1. **建立统一消息语法（Narrative UI Grammar）**  
   - 将消息拆分成：`SYSTEM` / `NARRATOR` / `PLAYER` / `ALERT` 四类固定标签、边框与前缀。  
   - 每类消息固定行高、字号、间距、左侧导轨颜色，减少“长文块视觉疲劳”。
2. **输入区升级为“命令行 + 意图辅助”**  
   - 在输入框前增加 prompt：`site://stdin >`。  
   - 提供可折叠“命令片段建议”（例如：移动、交涉、调查、收容），并将地图快捷动作与输入区统一。
3. **文本可读性优化**  
   - 为长段叙事设置“段间呼吸节奏”：每 3~5 行自动插入轻分隔（极低对比度）。  
   - 对可点击实体（SCP编号、编号选项）采用统一下划线与 hover 机制，避免与普通文本混淆。
4. **节奏灯（Pacing Indicator）**  
   - 新增一条极细“叙事压力条”（非稳定度），依据最近3轮文本中的风险词上升/下降，帮助玩家形成“剧情温度感”。

---

## 3) 侧边面板（左传承 / 右地图）

### 现状判断
- 左侧传承面板信息丰富，右侧地图面板功能实用（邻接、NPC、目标、小地图）。  
- 但两侧面板语言略偏“通用卡片”，离“基金会控制附屏”还差一个层次。

### 改进建议
1. **左右面板同构化（强烈建议）**  
   - 统一：标题条高度、标签样式、边框粗细、内边距单位、滚动条风格。  
   - 左右面板共享一个 `PanelFrame` 视觉规范，避免像不同子系统拼接。
2. **传承面板“档案编号化”**  
   - 每个 Trait/Item 不仅显示名称，增加 `LEGACY-ID`（如 `LGC-T-004`），并显示来源轮次。  
   - Echo 时间线可切“摘要/原文”双态；默认摘要，点击展开原文片段。
3. **地图面板战术化**  
   - 在邻接节点上增加风险标识（危险度、门禁等级、已知实体），形成“行动前态势图”。  
   - 小地图节点可增加“污染层”（认知危害节点呈琥珀/红闪边），而非仅状态点色。
4. **收起态增强**  
   - 收起后的窄栏应保留关键指标（例如传承数量、当前区块风险），而不是只保留图标。

## 4) 顶部信息栏

### 现状判断
- 已包含 SCP 名称、编号、角色、收容等级、回合、稳定度监控与菜单入口。  
- 信息齐全，但“中心标题 + 两侧信息”的视觉紧凑度可再优化。

### 改进建议
1. **信息优先级重排**  
   - 一级：稳定度、当前SCP编号、当前状态（正常/警戒/崩溃前兆）。  
   - 二级：角色、收容等级、回合数。  
   - 将二级信息折叠进可展开“INFO BLOCK”，减少顶部拥挤。
2. **稳定度组件专业化**  
   - 除数字外增加“实时波形”迷你图（近 10 回合），让玩家看到趋势而非瞬时值。  
   - 在阈值 crossing（70/30）时使用一致化转场（而非多处独立闪烁）。
3. **菜单图标语言替换**  
   - 目前设置菜单存在 emoji；建议统一为线性图标集（mono/duotone），避免破坏世界观。

## 5) 世界树界面（含 review）

### 现状判断
- 复盘结构完整：时间线、AAR、问答、导出、音频剧本、NG+入口。  
- 功能很强，但“世界树”视觉符号可进一步加强，当前更偏“报告容器”。

### 改进建议
1. **世界线可视化升级**  
   - 从“线性列表”升级为“分叉树”布局（至少在关键节点呈 fork），突出“命运织机”主题。  
   - 节点状态（成功/失败/异常干预）使用统一几何符号而非仅文本。
2. **Review与世界树联动**  
   - 点击报告中的关键指标（如心理压力峰值），高亮对应时间线节点。  
   - 支持“从节点回放片段”（scroll-to-message + 高亮3秒）。
3. **打印与屏显双版式**  
   - 当前导出流程已具备；建议将屏显版式更“战术控制台”，而打印版保持“官方事故报告”。

## 6) NG+ 传承特质选择界面

### 现状判断
- 支持 trait/item 选择上限与继承组合，机制合理。  
- 但“选择仪式感”与“代价感”可以更强。

### 改进建议
1. **加入“继承预算”机制可视化**  
   - 除数量上限外可加“记忆负载值”，高稀有特质消耗更高预算，提升策略深度。  
2. **双列表对照**  
   - 左侧“可继承池”，右侧“本次装配”，支持拖拽/双击迁移，直观体现配置过程。  
3. **叙事化确认文案**  
   - 确认按钮文案可改为：`COMMIT TO NEXT ITERATION`，并显示本轮将遗失/保留内容摘要。

## 7) 存档界面、游戏设置界面

### 现状判断
- 存档系统具备本地+云端同步、冲突处理、自动同步，工程能力很强。  
- 视觉上仍偏“管理后台感”，与主游戏终端风格割裂。

### 改进建议
1. **存档卡片“档案卷宗化”**  
   - 每条存档显示：档案号、时间戳、回合、结局标签、同步状态、校验摘要。  
   - 使用“纸档+终端叠层”视觉（暗底 + 压印号 + 条纹边），体现基金会档案质感。
2. **同步状态可解释**  
   - `已同步/待上传/待下载/冲突`用四态徽标 + tooltip 文案解释。  
   - 冲突时提供“以本地为准/以云端为准/比较后选择”三选项。
3. **设置页分组**  
   - 图形效果、音频、无障碍、叙事辅助分组；对“高风险视觉特效”给出强度滑杆与预览。

## 8) 通知、新手引导、视觉特效

### 现状判断
- 通知与特效触发逻辑完善（位置变更、目标完成、解锁等）。  
- 特效类型多，沉浸感强；但“强度管理”和“事件语义化”仍可加强。

### 改进建议
1. **事件语义到视觉语义映射表**（建议建立设计规范文档）  
   - 例如：
     - `LOCATION_ENTER` → 扫描线 + 青色提示；
     - `COGNITOHAZARD` → 色偏 + 文本重影；
     - `REALITY_FAILURE` → 红色脉冲 + 高频噪声；
     - `MEMORY_ECHO` → 暖色褪色 + 胶片颗粒。  
2. **分级特效管线**  
   - L0（无）~L3（强）可在设置中手动与自动（随稳定度）叠加控制。  
   - 避免多特效同时叠加导致信息不可读。
3. **新手引导“渐隐式”**  
   - 引导从一次性弹层改为“情境内提示”（在首次触发某功能时出现 1 条短提示），减少打断。
4. **无障碍增强**  
   - 除 `prefers-reduced-motion` 外增加：高对比主题、色盲友好状态色、字幕/提示持续时间可调。

## 9) 全局视觉系统建议（实现“高级感”的关键）

### A. 设计令牌（Design Tokens）统一
建议建立 tokens（可先在常量层）并替换散落的 Tailwind 颜色：
- `--scp-bg-0/1/2`：背景深度层
- `--scp-semantic-ok/warn/danger/info`
- `--scp-border-subtle/normal/strong`
- `--scp-glow-low/mid/high`
- `--scp-radius-none/sm`（建议整体收紧圆角）

### B. 图标系统统一
- 禁用 emoji 作为系统按钮主图标；统一线性图标（16/20/24 三规格）。
- 关键系统动作（保存、加载、终止、警报）采用同一笔触粗细与圆角半径。

### C. 动效原则
- “信息优先、特效其次”：特效不得覆盖核心文本可读性。
- 所有阈值触发动效（70/30、结束倒计时）用统一 easing/duration。
- 高级感来源于“克制 + 一致 + 节奏”，不是单纯“更多特效”。

### D. 排版与密度
- 基础字号阶梯固定（10/12/14/16/20/24）。
- 同类卡片统一内边距节奏（8/12/16），减少“每块都不一样”的拼贴感。

## 10) 分阶段落地路线图（可执行）

### Phase 1（1~2周，低风险高收益）
- 统一按钮/标签/边框/图标语言（去 emoji）。
- 建立颜色语义规范（ok/warn/danger/info）并替换关键模块。
- 顶部栏信息重排 + 稳定度趋势迷你图。

### Phase 2（2~4周，中等改造）
- 侧边栏同构化（PanelFrame）。
- 存档界面卷宗化改版 + 同步状态解释增强。
- 世界树关键节点可视化升级（至少关键分叉）。

### Phase 3（持续优化，体验拉升）
- 事件语义→视觉语义映射系统化。
- NG+继承预算与双列表交互。
- 引导系统改为情境触发式，完善无障碍策略。

---

## 结论

项目已经有了非常扎实的“终端沉浸 + SCP叙事”基础，真正需要的是**视觉系统化与语义一致性提升**。核心方向不是“推翻重做”，而是：

1) 统一视觉语法（颜色/边框/图标/动效）；
2) 强化基金会制度感（许可、档案编号、控制台术语）；
3) 让视觉反馈更像叙事的一部分，而非独立特效层。

只要按上述分阶段推进，本作能够从“优秀风格化界面”升级到“具有品牌辨识度与高级质感的SCP交互终端”。
