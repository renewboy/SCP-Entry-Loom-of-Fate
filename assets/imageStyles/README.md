# 生图风格

绘画风格应用于新生成的背景、SCP 实体、NPC 肖像和剧情插图。系统设置自动保存当前选择。

| 风格 | 绘画特征 | 参考图 |
| --- | --- | --- |
| 默认（原版） | 临床记录摄影、电影光照、低饱和色彩和胶片颗粒 | 无 |
| 版画叙事 | 平面色块、流线轮廓、交叠的几何明暗面、细密排线和印刷肌理 | `abstract.webp` |
| 幽境墨绘 | SCP 阴冷临床基调，叠加极简墨线角色、图形化轮廓、平涂阴影和幽静的氛围绘景 | 无，使用文字风格描述 |

## 版画叙事参考图

`abstract.webp` 是四类生图共同使用的抽象技法参考，提供线条、色块明暗关系、排线与印刷纹理，不含可识别的人物、实物或场景。灰阶用于表达明暗与材质；生成图的颜色、人物外观、服装和环境由当前主体描述决定。

`manifest.json` 记录这张资源的尺寸、来源和制作信息。

## 幽境墨绘的美术依据

[官方截图](https://www.hollowknight.com/)中的蓝色洞窟、绿色湖畔与画师战斗画面提供了绘画技法和氛围渲染依据：流畅的深色外轮廓、稀疏的内部线条、概括的角色造型、平涂色面、柔和光晕和前后景明度分离。

“幽境墨绘”的四类模板保留原版的 `scp foundation style`、clinical、dark atmosphere、desaturated 与 cold muted tones 等基调，采用《空洞骑士》的手绘造型、墨线、平涂阴影和氛围绘景处理。模板只定义绘画风格、基调和类别用途，不指定具体地点、建筑、道具或剧情场景。

## 配置与调用

`services/ai/imageStyles/` 中每个风格模块定义显示名称的翻译键、背景/实体/NPC/剧情四类生图模板和参考图加载方法，`index.ts` 注册全部风格。设置选项、设置读取和生图服务使用这一注册表。

主体描述原样传入选定的类别模板，绘画风格由模板附加。`visualDescription` 提供材质、氛围和空间提示词；`entityDescription` 只描述实体外观，不含动作和背景；`npcVisuals` 描述人物外观；剧情 `[VISUAL]` 提供当前画面内容。

`services/ai/promptUtils.ts` 选择风格与类别模板，传入主体描述并附加输出比例。背景与剧情场景使用桌面 16:9 或窄屏 9:16，实体与人物肖像使用 1:1。参考图仅由对应风格的加载方法提供。
